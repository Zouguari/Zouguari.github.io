SAP

Purchase Request & Approval

Application Fiori de demande d'achat avec circuit d'approbation, intégrée au module MM de SAP S/4HANA.

Voir le code sur GitHub
Le problème
Les demandes d'achat doivent être approuvées avant d'engager une dépense, avec des règles de contrôle strictes : un employé ne peut pas valider sa propre demande, et chaque approbateur a une limite de montant.
La solution
Une application transactionnelle Fiori Elements développée avec RAP sur SAP S/4HANA 2021. Les employés créent leurs demandes, les approbateurs les approuvent ou les rejettent avec un motif obligatoire, et chaque demande approuvée génère automatiquement une demande d'achat standard SAP (MM) via BAPI_PR_CREATE, appelée dans la phase de sauvegarde selon le pattern « managed with additional save ». Séparation des tâches, limites d'approbation, actions selon le statut et visibilité selon le rôle sont garanties côté serveur.
Ma contribution
Conception et développement complets, du modèle de données CDS jusqu'à l'interface Fiori, avec 7 tests unitaires ABAP (EML et test double SQL) qui ont permis de détecter et corriger un vrai bug d'ordre d'exécution des déterminations.

SAP

Vendor Spend Intelligence

Extension SAP BTP qui fiabilise les données fournisseurs de S/4HANA Cloud grâce à l'IA.

Voir le code sur GitHub
Le problème
Dans les grandes entreprises, les équipes achats souffrent de données fournisseurs peu fiables : des doublons créés par des conventions de nommage incohérentes, et des blocages d'achat qui passent inaperçus.
La solution
Une extension side-by-side SAP BTP développée en CAP Node.js, connectée en temps réel à un système S/4HANA Cloud via l'API standard API_BUSINESS_PARTNER. Un moteur de règles détecte les fournisseurs bloqués, un LLM regroupe les doublons approximatifs avec un score de confiance, et un tableau de bord au thème SAP Horizon présente les résultats. Le cœur de l'ERP reste intact.
Ma contribution
Conception et développement complets, de l'intégration S/4HANA via Communication Arrangement jusqu'au tableau de bord, avec une gestion sécurisée des identifiants par variables d'environnement.

SAP

Interface IDoc de commandes clients

Intégration automatisée des commandes d'une boutique externe dans SAP S/4HANA, en ABAP classique.

Voir le code sur GitHub
Le problème
Les commandes reçues d'un système externe doivent être intégrées dans SAP de façon fiable, avec un suivi des erreurs et la possibilité de corriger sans tout ressaisir.
La solution
Une interface IDoc complète : type d'IDoc et segments personnalisés, module fonction d'entrée créant les commandes clients via BAPI, journalisation dans une table dédiée, et un rapport de monitoring ALV qui permet de suivre les IDocs et de retraiter ceux en erreur en un clic. Scénarios testés : succès, erreur, correction et retraitement.
Ma contribution
Conception et développement complets, de la configuration ALE (partenaires, code de traitement) jusqu'au monitoring.

Odoo

SmartERP AI

Plateforme SaaS d'aide à la décision et agent IA conversationnel pour Odoo 17.

Voir le code sur GitHub
Le problème
Les dirigeants de PME ont toutes leurs données dans Odoo (ventes, CRM, stocks, recouvrement), mais pas le temps ni les outils pour les analyser et décider vite.
La solution
Une plateforme qui synchronise en arrière-plan les données d'Odoo 17 vers une base analytique PostgreSQL, sans ralentir l'instance de production. Elle propose des KPI en temps réel, un score de santé de l'entreprise sur 100, une analyse automatique des causes racines, des recommandations générées par l'IA, des alertes configurables, des rapports par email et un agent conversationnel capable de répondre avec des chiffres réels.
Ma contribution
Projet de fin d'année en équipe de trois, en partenariat avec UrikaCloud, en tant que développeur full stack. J'ai notamment mené un audit complet de bout en bout : suppression des données simulées, correction des erreurs de mapping avec Odoo, journaux d'audit et sécurisation des actions déclenchées dans Odoo.

Smart HR AI

RH automatisée sur Odoo 17, du recrutement à l'évaluation, avec IA et application mobile.

Voir le code sur GitHub
Le problème
Tri des CV, matching poste/candidat, suivi des congés, des présences et des évaluations restent souvent manuels, et les collaborateurs n'ont aucune visibilité sur leurs propres données RH.
La solution
Six modules Odoo custom qui automatisent le recrutement (extraction de CV avec OCR, scoring IA, embauche avec création de l'employé, du contrat et de l'onboarding), les compétences, les congés, les présences et les évaluations. Une API REST sécurisée par JWT, avec des droits par rôle, alimente une application mobile où chaque employé consulte son profil, ses congés et ses évaluations.
